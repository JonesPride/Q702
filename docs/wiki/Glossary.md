# Q702 — Glossary

- **NFT:** Non-fungible token; the contract in this repository implements an ERC-721 token.
- **ERC-721:** Ethereum token standard implemented by the `NFT` contract.
- **Truffle:** Development framework used to compile and test the Solidity contract.
- **Ganache CLI:** Local Ethereum development node dependency used with the configured Truffle development network.
- **Token URI:** Per-token metadata reference stored by the contract.
- **EIP-712:** Typed structured-data hashing/signing standard used by the contract's voting extension.
- **ERC-721 Votes:** OpenZeppelin extension that adds voting/checkpoint functionality to ERC-721 tokens.
- **Repository:** The GitHub project named Q702.
