# Q702 — Security & Operations

## Current evidence
No implementation details or operational controls are documented in the README.

## Security questions before use
- Does the repository contain smart contracts or wallet-signing code?
- Are private keys, API tokens, or deployment secrets required?
- Is metadata hosted locally, on IPFS, or through another service?
- Are contracts upgradeable, and who controls administrative permissions?
- Are there external dependencies or privileged deployment scripts?

## Safety boundary
No wallet connection, signing, deployment, transaction, or credential handling is authorized or documented by this page. Inspect source and permissions before any operational action.
